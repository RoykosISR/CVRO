# CVRO - Compact VR Overlay

A wrist watch and menu for SteamVR: your Windows desktop and windows in VR, a VR keyboard, music controls, notifications, a timer and more.

Created by Roykos_ISR.

## Download

Get the newest installer from [Releases](https://github.com/RoykosISR/CVRO/releases) (`CVRO-Setup-<version>.exe`).
CVRO checks this page for updates (CVRO Settings > About > Check for updates).
